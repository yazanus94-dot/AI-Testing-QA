Quick start

  • Install: pip install -r requirements.txt
  • Run pipeline: python run_qa.py (reports in reports/)
  • CI gate mode: python run_qa.py --fail-on-gate
  • Tests: pytest -q

What you get

  • Release-style quality gate (PASS / FAIL / warnings)
  • Explainable, severity-ranked findings with evidence
  • Metrics, evaluator self-checks, and recommendations
  • Test plan, cases, bug reports, and reproducible sample data
